# Chen Agent — Web Researcher

## Overview

חן היא הסוכן הרביעי שנוסף לרוסטר (אחרי ראובן, יובל, יעל). תפקידה: לקבל מראובן בקשת מחקר, לחפש ברשת מקורות איכותיים (WebSearch + WebFetch), לבחור את הטוב ביותר, ולהניח אותו כקובץ ב-`Content/` (תיקיית הקלט של יעל). הערך מעבר ל-LLM רגיל: מידע עכשווי, מקורות אמיתיים עם לינקים, ללא הזיות.

**Tools:** WebSearch, WebFetch, Read, Write, Edit, Glob, Grep — בלי Bash, בלי MCP, בלי API חיצוני.

**זיכרון חיפושים:** `chen/Memory/searches.md`. לפני כל חיפוש חדש חן עושה Grep על מילות המפתח לבדוק האם בוצע חיפוש דומה ב-30 הימים האחרונים. אם כן ולא דינמי — היא מחזירה לראובן את השאלה האם לעבוד על הקיים או לחפש מחדש (במקום לבזבז קריאות רשת).

**Chaining ליעל:** חן לא קוראת ליעל ישירות (אילוץ Claude Code: סאב-אייג'נטים לא מפעילים סאב-אייג'נטים). היא רק מניחה קובץ ב-`Content/` ומחזירה לראובן. ראובן מחליט אם להמשיך אוטומטית ליעל לפי כוונת המשתמש המקורית: אם הוא ביקש רק "מצא מאמר" — ראובן עוצר; אם ביקש "מצא ושכתב" — ראובן מאציל ליעל את הקובץ שחן יצרה.

**מבנה קבצים:** הגדרה קנונית ב-`.claude/agents/chen.md` (flat, עם `tools:` שמכיל WebSearch+WebFetch), תיקיית עבודה `chen/` בשורש (Memory/searches.md + agent.md pointer doc).
